# 🎨 Assinatura de E-mail

Repositório com os assets e o código HTML da minha assinatura de e-mail profissional.

## 📁 Estrutura

- `assets/` — Imagens (foto de perfil e ícones das tecnologias)
- `signature.html` — Código HTML da assinatura

## 🚀 Como usar

1. Abra o arquivo `signature.html` no navegador.
2. Selecione tudo (Ctrl+A) e copie (Ctrl+C).
3. Cole no campo de assinatura do Gmail (Ctrl+V).
4. Pronto! A assinatura será renderizada com as imagens.
